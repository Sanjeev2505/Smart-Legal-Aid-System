
# Smart Legal Aid System

## Overview
Smart Legal Aid System is an NLP-based application designed to process
legal queries and retrieve relevant legal information.

## Features
- Legal query processing
- Query classification
- Semantic search
- Relevant legal information retrieval
- Legal document generation
- Petition and notice assistance

## Technologies
- Python

- Semantic Search
- Backend System Design
